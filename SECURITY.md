# Security policy

This is experimental local CAD/firmware automation, not a hosted service.
The latest tagged version is the focus of security fixes; older versions have
no separate maintenance commitment.

Do not publish exploit details, credentials or confidential design files in an
ordinary issue. If GitHub offers **Security → Report a vulnerability**, use it.
Otherwise use the contact details linked from the
[maintainer's profile](https://github.com/joxerx).

Include the affected version, a minimal synthetic reproduction, impact,
platform/tool versions and any workaround. Do not send production credentials
or unrelated design data. There is no guaranteed response SLA or bug bounty.

Ordinary reproducible bugs, feature requests and questions can use GitHub
issues. Native ERC/DRC acceptance is not a security or hardware certification.
